# Screenshots

Visual captures of `precision-block-stack` live in this directory to document the rendered interface across viewports:

- **Start overlay (`ready`):** shows the initial 3-slab preview tower, audio reactivity controls (`Test Tone`, `SFX`), and quick-start actions (`Start Stacking` / `Start with Test Tone`).
- **Active gameplay (`playing`):** shows the 2.5D extruded tower, `10F`/`20F` altitude markers, `ON BEAT` golden frame, 28-bin background spectrum, and falling sliced overhangs.
- **Mobile (`390×844`):** verifies single-row HUD controls and `2×2` Game Over stats layout.
